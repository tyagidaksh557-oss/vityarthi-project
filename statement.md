# CollegeMate - Project Statement

## Problem Statement

College students regularly need to manage academic information such as
attendance, assignments, grades, and personal expenses. These tasks are
often handled separately or manually, which can make it difficult to
keep track of important student information.

CollegeMate aims to provide a simple Python-based student utility
application that brings several common student tasks together in one
menu-driven program.

## Scope of the Project

The project focuses on developing a basic student utility system using
Python programming concepts. The current scope includes:

-   CGPA calculation
-   Attendance calculation
-   Assignment tracking
-   Expense tracking
-   Access to saved data
-   Menu-based navigation

The project is designed as a foundation that can later be expanded with
more advanced features and persistent data storage.

## Target Users

The primary target users are:

-   College students
-   Undergraduate students
-   Students who want a simple utility for managing common academic and
    personal tasks

## High-Level Features

### CGPA Calculator

Calculates CGPA using academic information entered by the user.

### Attendance Calculator

Calculates attendance percentage using attended and total class
information.

### Assignment Tracker

Helps students record and keep track of assignment information.

### Expense Tracker

Allows students to record and manage their expenses.

### Saved Data

Provides access to information maintained by the application.

## Technical Approach

CollegeMate is implemented using Python and applies basic programming
concepts including:

-   Functions
-   Variables
-   Input/output
-   Conditional statements
-   Loops
-   Basic calculations
-   Menu-driven program flow
-   Input validation and error handling where implemented

## Expected Outcome

The expected outcome is a functional, easy-to-use student utility
program that demonstrates the practical application of Python
programming concepts to a real-world student problem.

## Future Scope

The project can be enhanced by adding:

-   A graphical user interface
-   Database storage
-   User authentication
-   Assignment reminders
-   Attendance alerts
-   Detailed expense reports
-   Additional student utilities
