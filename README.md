# CollegeMate

## Project Overview

CollegeMate is a Python-based student utility application designed to
help college students manage common academic and personal tasks from one
simple menu-driven program.

The project provides multiple utilities including CGPA calculation,
attendance calculation, assignment tracking, expense tracking, and saved
data access.

## Features

### 1. CGPA Calculator

-   Accepts academic subject/grade information from the user.
-   Calculates and displays the CGPA based on the entered values.

### 2. Attendance Calculator

-   Accepts the number of classes attended and the total classes
    conducted.
-   Calculates the current attendance percentage.
-   Helps the student understand their attendance status.

### 3. Assignment Tracker

-   Allows the user to enter and track assignment-related information.
-   Helps students keep track of their academic work.

### 4. Expense Tracker

-   Provides a simple way to record and manage student expenses.

### 5. Saved Data

-   Provides access to saved information used by the application.

## How to Run

1.  Install Python 3.x on your computer.
2.  Download or clone this repository.
3.  Open a terminal in the project folder.
4.  Run:

``` bash
python main.py
```

5.  Follow the menu displayed by the program.

## Testing

The application can be tested by running `main.py` and checking each
menu option with valid and invalid user inputs.

Important test areas include: - CGPA calculation - Attendance percentage
calculation - Assignment entry and tracking - Expense entry - Menu
navigation - Exit functionality

## Project Objective

The objective of CollegeMate is to apply Python programming concepts to
a practical student-focused problem and create a simple utility
application that can be extended with additional features in the future.
